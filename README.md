# MCT-systems-Design
# Modular Omni Wheel Mobile Manipulator Project 

## Structure
- `STM_Base/` — STM32F401RCT6 CubeIDE project
- `STM_Arm/` — STM32F103C8T6 CubeIDE project
- `PI/` — Raspberry Pi Python code
- `Controllers/` — Esp32 & Arduino Nano code
